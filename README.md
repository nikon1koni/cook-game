# 厨房乱斗 · 把摇到的菜做出来

用「今天吃什么」里的 **64 道菜** 做的小游戏：先摇一道菜，再完成四道厨房关卡。

## 玩法

1. **摇菜**：老虎机从 64 道菜里摇一道（日常餐食 + 调理食谱都在池子里）
2. **备菜**：从 8 个食材里选出这道菜需要的 3～4 样，选错扣 5 分
3. **火候**：指针进绿区时点「下锅」，3 锅，完美 +10 / 偏一点 +5 / 糊了 +0
4. **调味**：4 选 1，选出这道菜需要的关键调味
5. **装盘**：4 秒内快速点 12 下，按剩余时间给 14～20 分

四关满分 100：

- 85 分以上：★★★ 完美出锅
- 65～84：★★ 味道不错
- 65 以下：★ 能吃

## 其他

- 图鉴：做过的菜会记录在 localStorage，目标 64/64
- 音效：WebAudio 实时合成，可关闭
- 纯静态单文件，无外部依赖，微信内可直接打开
- 菜谱数据来自 [meal-slot](https://github.com/nikon1koni/meal-slot)
